## 👋 À propos de moi
 
Je suis **étudiant en 2ᵉ année de BUT Informatique** à l'IUT Robert Schuman (Illkirch).
 
Ce qui m'anime, c'est la frontière entre **le code et le design** : concevoir des règles de jeu équilibrées, construire des interfaces lisibles, et surtout travailler le **feeling**, ce petit quelque chose qui fait qu'une application ou un jeu est agréable à prendre en main.
 
- 🎮 **Game design** : j'invente des mécaniques, je les écris, puis je les prototype
- 🖌️ **UI & ergonomie** : chartes graphiques, maquettes, création d'assets visuels
- 🧠 **Développement** : programmation orientée objet, bases de données, tests
## 🔍 Ce que je recherche
 
Un **stage de 50 jours (avril → juin 2027)**, idéalement **en Alsace**, dans une structure qui mêle **informatique et design** : studio de jeu vidéo, agence web/UI, équipe produit…
Si c'est votre cas, je serais ravi d'échanger ! 📬
